# 🪔 Krishna Rathwa — Personal Developer Portfolio

An Indian Heritage & Traditional Art-inspired modern developer portfolio built with **Next.js 16 (App Router)**, **TypeScript**, and **Tailwind CSS**.

Inspired by classical Indian aesthetics — blending rich jewel and earthy tones (terracotta, ochre, forest green, gold, warm ivory), Devanagari/classical serif typography (Cinzel Decorative, Playfair Display), and traditional architectural & geometric motifs (Mandala line art, Jali lattice patterns, temple borders).

🔗 **GitHub Repository:** [https://github.com/rkrishna04/krishna-portfolio](https://github.com/rkrishna04/krishna-portfolio)

---

## 🏛️ Sections & Philosophy

- **🙏 The Namaste (Introduction):** Narrative-driven welcome presenting credentials, philosophy of craftsmanship (*kārigari*), roles, and key statistics.
- **🎨 Kala (The Craft / Technical Mastery):** Categorized matrix of Programming Languages, Data Analytics, Databases, Tools, and Professional Competencies.
- **📜 Katha (The Stories / Works):** Curated gallery of projects framed in miniature painting and archival scroll aesthetics:
  - **Expense Tracker** (Python, SQL)
  - **TTF — The Tasty Food** (PHP, MySQL, Web Stack)
  - **Online Multiplayer Game** (Unreal Engine, C#, Blender)
  - **HealTrack** (React, Python, Machine Learning)
  - **Sales Analytics Dashboard** (Power BI, SQL, Excel)
- **⚙️ Karigari (The Craft Journey / Experience):**
  - **Western Railway** (Vadodara) — Enterprise Internships (NOCC ROOT & WRSIMS)
  - **Education:** MCA (Artificial Intelligence) & BCA (Full Stack Web Development) with Distinction from Parul University
  - **Certifications:** NVIDIA Deep Learning Institute, IIT Bombay
- **💬 Samvad (The Dialogue / Contact):** Interactive inquiry section with direct contact channels (Email, Phone, LinkedIn) and quick-action message trigger.

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/rkrishna04/krishna-portfolio.git
cd krishna-portfolio

# Install dependencies
npm install

# Run development server
npm run dev
```

Visit `http://localhost:3000` in your browser.

---

## ☁️ Deploying on Vercel

### Option 1: Vercel Web Dashboard (Recommended for Continuous Deployment)
1. Go to [vercel.com/new](https://vercel.com/new).
2. Connect your GitHub account and select the **`krishna-portfolio`** repository.
3. Click **Deploy**. Vercel will automatically detect Next.js and deploy your portfolio live with free SSL.
4. Future pushes to the `main` branch will automatically re-deploy.

### Option 2: Deploy via Vercel CLI
```bash
vercel --prod
```
